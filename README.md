## Products

- **[Velora](https://velora-store-navy.vercel.app)** — a live Arabic-first cosmetics store taking real orders today. React storefront made for phones first, three-step checkout with live validation, promo codes that start and stop on schedule, Telegram order alerts, and an admin dashboard for products, orders and campaigns. Firebase backend with server-side security rules, hosted on Vercel.
- **[Altareq](https://altareq.vercel.app)** — an Arabic learning platform where students ask grammar questions and get instant answers from an AI assistant named Nour. Courses, quizzes and certificates. Designed and built solo.
